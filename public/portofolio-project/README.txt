# Folder Penyimpanan Gambar Proyek (Tab Project)

Folder ini digunakan untuk menyimpan seluruh gambar proyek yang akan ditampilkan pada Tab "Project" di menu Portofolio.

## Lokasi Gambar:
- Simpan file gambar Anda di dalam folder:
  `public/portofolio-project/images/`
  atau langsung di dalam `public/portofolio-project/`
- Format yang didukung: `.jpg`, `.jpeg`, `.png`, `.webp`, `.svg`.

## Catatan:
- Pada halaman Project, item proyek akan ditampilkan dalam bentuk kartu portofolio visual dengan gambar, judul, deskripsi, metrik hasil, dan teknologi yang digunakan.
- Sesuai instruksi: Halaman project **tidak menggunakan klik preview interaktif (iframe)** seperti pada tab Karya.
