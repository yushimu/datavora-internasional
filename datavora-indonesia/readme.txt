Professional Corporate WordPress Block Theme for DATAVORA INDONESIA - Turning Data Into Business Solutions.

== Description ==

DATAVORA INDONESIA is an enterprise-grade WordPress Block Theme built specifically for data solutions, analytics consulting, business process automation, and technology services companies.

Built natively on WordPress Full Site Editing (FSE) architecture with:
* Full Site Editor support (theme.json v2 compliant)
* 6+ Pre-built Block Patterns (Hero, 8 Core Services, About & Values, 5-Step Methodology, Demonstrasi Portofolio, and High-converting CTA)
* Standardized corporate brand colors: Deep Navy Blue (#102A43), Royal Blue (#2563EB), Cyan Accent (#06B6D4), Light Background (#F4F7FB)
* Responsive design for Desktop, Tablet, and Mobile
* Zero unnecessary dependencies or paid plugin lock-ins

== Installation ==

1. Unduh file `datavora-indonesia.zip`
2. Masuk ke WordPress Dashboard Anda (wp-admin)
3. Navigasi ke: Tampilan (Appearance) -> Tema (Themes) -> Tambah Baru (Add New Theme) -> Unggah Tema (Upload Theme)
4. Pilih file `datavora-indonesia.zip` lalu klik "Pasang Sekarang" (Install Now)
5. Klik "Aktifkan" (Activate)
6. Masuk ke menu Editor (Site Editor) untuk menyesuaikan teks, menu navigasi, dan logo perusahaan sesuai kebutuhan Anda!
